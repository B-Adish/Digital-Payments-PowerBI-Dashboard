# Digital Payments Analytics Dashboard

## About the Project

This project is a Power BI dashboard created to analyze digital payment data.

The dashboard covers transactions, users, banks, payment methods, and merchants. It helps to understand transaction performance, user preferences, fraud-related transactions, and other payment-related trends.

## Dashboard Pages

### 1. Transaction Analysis

This page focuses on transaction-related information such as:

- Total Transaction Amount
- Total Transactions
- Success Rate
- Successful Transactions
- Average Transaction Amount
- Transactions by day of the week
- Fraud and non-fraud transactions
- Transaction status
- Payment app analysis

### 2. User Analysis

This page looks at user-related data such as:

- Total Users
- Average Monthly Transactions
- Revenue Per User
- Transactions Per User
- Preferred Payment Apps
- KYC Status
- Preferred Devices
- Age Groups
- User City Tier

### 3. Bank & Payment Methods Analysis

This page contains analysis related to banks and payment methods, including:

- Active Banks
- Average Bank Rating
- Highest Daily Limit
- Top Payment Method
- Bank Revenue
- Payment Methods
- Processing Fees
- Security Level

### 4. Merchant Analysis

This page focuses on merchant-related information such as:

- Registered Merchants
- Total Merchants
- Average Merchant Rating
- Average Daily Transactions
- Merchant Categories
- City Tier
- Merchant Size
- Failed Transactions
- Transaction Velocity
- Fraud Analysis
